# One Line, No Deadline Met

One single-line joke giving an excuse for missing a deadline, capped at
200 characters. A model judge compares entries two at a time against the
published brief: on-subject first, then funny, one-line form, sounds like
something a person would actually say, and fresh.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

The program writes exactly one line to `entry.txt` in the output directory.
